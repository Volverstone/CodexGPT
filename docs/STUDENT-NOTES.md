# Заметки об учениках

Локальная версия для просмотра, без публикации до одобрения пользователя.

- В строке ученика рядом с карандашом есть кнопка с изображением листка.
- Подсвеченный значок с точкой означает, что у ученика есть заметка.
- Нажмите кнопку, введите до 2000 символов и сохраните. Поддерживаются переносы строк.
- Для удаления очистите поле и сохраните; отмена не меняет прежний текст.
- Заметка относится к ученику в целом, не к конкретной дате, лекции или месяцу.
- Редактирование контактов, посещаемости, пополнений не сбрасывает заметку.
- Заметки включаются в экспорт/импорт и общий журнал аккаунта. Доступны только владельцу журнала; другие аккаунты их не видят.

`npm run preview` создаёт автономный `preview-notes.html` с демонстрационными данными и обоими цветовыми режимами. Демо не обращается к рабочей базе.

Для публикации потребуется одобрение, экспорт резервной копии и полное выполнение `supabase/migrations/004_student_notes.sql` в Supabase SQL Editor. SQL включает предыдущие изменения, добавляет поле students.notes с пустым значением по умолчанию и обновляет функции загрузки/сохранения. Существующие ученики, пополнения и посещаемость сохраняются. В состоянии журнала используется version:4; старые резервные копии автоматически преобразуются с пустыми заметками.

До обновления SQL новая версия покажет старый журнал только для просмотра и предложит ссылку на SQL. В настоящей базе миграция при подготовке просмотра не выполнялась.
