# Класс — журнал учеников

Ученики, группы, телефон, дата присоединения, депозит и посещаемость. Русский интерфейс для компьютера, Android и iPhone.

**[Подключить SQL-базу и синхронизацию: пошаговая инструкция](docs/SETUP-RU.md)**

## Общая база

Приложение поддерживает Supabase (PostgreSQL + вход по email/паролю). SQL: [supabase/schema.sql](supabase/schema.sql). Таблицы `students`, `attendance`, `journals`, разделение данных по аккаунтам, защита от устаревших записей с другого устройства. На всех устройствах нужен **один аккаунт**. Обновления загружаются каждые 10 секунд или кнопкой «Обновить».

Облачный проект ещё нужно создать в своём аккаунте Supabase, выполнить SQL и задать публичные настройки сборки. Без них сайт работает локально, без синхронизации. Реальная облачная база не создаётся загрузкой кода в GitHub.

## Netlify

Подключите `Volverstone/CodexGPT`, ветку `main`, к существующему сайту через Git. `netlify.toml` задаёт `npm run build` и папку публикации `dist`.

Переменные сборки: `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` (допускается старое имя `SUPABASE_ANON_KEY`). Только публичный publishable/anon-ключ, никогда service_role, sb_secret или пароль базы. Изменение переменных требует новой сборки. Записи учеников идут прямо в Supabase и **не требуют** пересборки сайта. Изменение SQL-структуры выполняется отдельно от Netlify.

## Скачать локальную версию

- [classroom-netlify.zip](https://github.com/Volverstone/CodexGPT/raw/refs/heads/main/classroom-netlify.zip) — готовая локальная версия, загружается в Netlify Drop целиком. `index.html` лежит в корне архива. `classroom-site.zip` — тот же пакет.
- [index.html](https://github.com/Volverstone/CodexGPT/raw/refs/heads/main/index.html) — отдельный HTML со встроенным кодом и стилями.
- Исходники: **Code → Download ZIP**.

Архивы в GitHub собраны без вашего Supabase. Ручная загрузка ZIP не подставляет переменные Netlify — для облачной версии используйте сборку из Git. Никаких учеников или учётных данных в архивах нет.

## Разработка

Node.js 20+, без внешних runtime-зависимостей:

```sh
npm test
npm run build
npm start
```

Сервер: порт 3000, другой порт — `PORT=3001 npm start`. Повторный запуск распознаёт уже работающий «Класс». `npm run dev` перезапускает сервер; после изменения клиента выполните `npm run build`.

Для облачной сборки задайте два публичных параметра в окружении сборки. Для локальной не задавайте их. Сборка отклоняет неполную конфигурацию и приватные ключи.

Исходники: `src/index.template.html`, `app.js`, `src/model.js`, `src/cloud.js`, `styles.css`. Сборка создаёт автономный `index.html`, `dist/` и два ZIP. Сгенерированный HTML не редактируется вручную.

## Данные

Без базы используется localStorage конкретного браузера. При запрете хранилища отображается предупреждение, изменения живут только в памяти. Повреждённые локальные данные не перезаписываются автоматически.

С базой загружается журнал вошедшего пользователя, сохранение подтверждается после ответа сервера. Старые локальные записи не отправляются автоматически: сначала экспорт, затем вход и импорт. **Импорт полностью заменяет общий журнал**. Аккаунт и токены не попадают в экспорт. Запись в облако без интернета не поддерживается.

Экспорт содержит телефоны учеников; храните копии бережно. Выйдите из аккаунта на общих устройствах. Для переноса старых раздельных журналов сначала сохраните все копии.

## Проверки

`npm test`: модель, валидация, auth, обновление сессии, конфликты, отсутствие сети. SQL-проверки с необязательным PGlite (зависимость не требуется для приложения):

```sh
npm install --prefix /tmp/classroom-pgcheck --cache /tmp/classroom-npm-cache @electric-sql/pglite
node supabase/verify.mjs /tmp/classroom-pgcheck/node_modules/@electric-sql/pglite/dist/index.js
```

Проверяется реальный PostgreSQL в WASM: транзакции, RLS, два аккаунта, конфликты версий, откат некорректного импорта. Подключение к настоящему Supabase проверяется после настройки вашего проекта по инструкции.
