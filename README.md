# Класс — журнал учеников

Первая версия приложения для учёта учеников и посещаемости. Интерфейс на русском языке, адаптирован для телефона и компьютера.

## Скачать готовое приложение

- [Готовый архив сайта classroom-site.zip](https://github.com/Volverstone/CodexGPT/raw/refs/heads/main/classroom-site.zip) — распакуйте и загрузите папку `dist` на статический хостинг, например Netlify Drop.
- [Отдельный HTML-файл](https://github.com/Volverstone/CodexGPT/raw/refs/heads/main/index.html) — скачайте и откройте в полноценном браузере.
- Все исходники: кнопка **Code → Download ZIP** на странице репозитория.

Готовый архив не содержит данных учеников. После размещения сайта откройте выданную HTTPS-ссылку в Chrome на Android и выберите **⋮ → Добавить на главный экран**.

## Запуск

Для просмотра скачайте `index.html` и откройте в обычном браузере. Все стили, код и значок встроены в файл; сервер и установка зависимостей не нужны. HTML-просмотрщик в файловом менеджере может не запускать JavaScript — используйте полноценный браузер.

Для разработки нужен Node.js 20 или новее. Внешних зависимостей нет.

```sh
cd /workspace/CodexGPT
npm start
```

Сервер слушает порт 3000. Другой порт: `PORT=3001 npm start`. Если на порту уже работает «Класс», повторный запуск сообщит об этом без стека ошибки. Если порт занят другим приложением, выберите другой порт. Проверки модели данных: `npm test`.

`npm run build` создаёт автономный `index.html` и папку `dist/` для статического хостинга. `npm start` и `npm run dev` выполняют сборку перед запуском. Исходная разметка находится в `src/index.template.html`, логика в `app.js` и `src/model.js`, стили в `styles.css`. После изменения клиентского кода повторите `npm run build` и обновите страницу. Не редактируйте сгенерированный `index.html` вручную.

## Возможности

- Добавление, редактирование и удаление учеников: имя, группа, дата присоединения, телефон.
- Отметка депозита «пополнен / не пополнен», без учёта суммы.
- Посещаемость на выбранную дату: присутствует, отсутствует, уважительная причина. Можно убрать отметку. До даты присоединения отметки недоступны.
- Поиск по имени и телефону, фильтры по группе и депозиту.
- Статистика посещаемости за выбранную дату и общий статус депозитов.
- Экспорт JSON-копии и импорт с проверкой формата и подтверждением замены.
- Локальное хранение и офлайн-работа после первого успешного открытия на HTTPS или localhost.

Группы создаются при заполнении карточки ученика; существующие названия предлагаются автоматически. Для редактирования нажмите на имя или значок карандаша. Для изменения депозита нажмите его статус.

## Где хранятся данные

Данные хранятся в localStorage браузера на конкретном устройстве и адресе сайта. Аккаунтов, синхронизации, облачной базы данных и авторизации пока нет. Очистка данных браузера удаляет журнал. Регулярно экспортируйте копию; она содержит персональные данные, включая телефоны. Данные приложения не отправляются серверу. Не используйте общее устройство для настоящего журнала без отдельного защищённого профиля.

Некоторые встроенные предпросмотры и браузеры запрещают localStorage. В этом случае приложение показывает постоянное предупреждение и работает только в памяти до закрытия страницы; используйте экспорт для сохранения. Повреждённые сохранённые данные не перезаписываются автоматически. Для реального журнала используйте постоянный HTTPS-адрес и обычный профиль браузера.

## Телефон и будущий APK

На Android файл `index.html` можно скачать и открыть в браузере, если он поддерживает локальные HTML-файлы. Встроенный просмотрщик загрузок может показывать только статическую страницу. Для постоянного использования удобнее сайт:

1. Выполните `npm run build` (готовая папка `dist/` уже собрана в текущей среде).
2. Разместите **содержимое `dist/`** на статическом HTTPS-хостинге. Например, на компьютере откройте https://app.netlify.com/drop и перетащите папку `dist` (может потребоваться вход в аккаунт). Если используете подготовленный `classroom-site.zip`, сначала распакуйте его.
3. Откройте выданную хостингом HTTPS-ссылку в Chrome на Android.
4. В меню Chrome выберите «Добавить на главный экран» или «Установить приложение» — название зависит от версии браузера. На HTTPS доступны манифест, значки 192/512 px и сервис-воркер для офлайн-запуска после первого открытия.

Публикация облачной **среды разработки** не является размещением сайта и не выдаёт публичную ссылку на приложение. Облачный localhost недоступен с телефона. В этом репозитории настроена статическая сборка, но внешнее размещение сайта не выполнялось.

Эта версия — веб-приложение, не APK. Для Android APK следующим этапом можно добавить Capacitor, Android-проект и подписанную сборку. Android-пакет, подпись и проверка на физическом устройстве пока не выполнялись. Перед сменой адреса, переносом на телефон или в APK экспортируйте данные и импортируйте их на новом устройстве: хранилище не переносится автоматически.

## Проверка вручную

Добавьте ученика, выберите дату после его присоединения, поставьте отметку и перезагрузите страницу. Проверьте другую дату, переключение депозита и фильтры. Экспортируйте JSON, удалите ученика и восстановите копию. Для сохранности журнала импорт и удаление требуют подтверждения.
